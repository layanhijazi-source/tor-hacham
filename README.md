# תור חכם (Tor Hacham)

אבטיפוס של אפליקציה לניהול תורים ושירות לקוחות במכון קוסמטיקה באמצעות סוכן.
פרויקט לימודי. מגישות: קמר עבידאת, לנה אסעד, ליאן חגאזי.

> **סביבת הדגמה בלבד.** כל הנתונים פיקטיביים. אין חיבור אמיתי ל-WhatsApp, לתשלום או לשרת, והסוכנת מבוססת כללים ומילות מפתח (לא מודל AI).
> יעדי ההצלחה באפיון הם יעדי בדיקה, לא תוצאות שהושגו.

## הבעיה
במכון קוסמטיקה הודעות ותורים מנוהלים ידנית ב-WhatsApp. בזמן טיפולים פניות מצטברות, ותור שבוטל ברגע האחרון קשה למלא.
לפי הערכה מראיון עם בעלת מכון אחת: כ-50 הודעות ביום, כ-6 ביטולים בשבוע, וכ-2 מהם מתמלאים (כ-33%).

## מה יש בגרסה 1
- שיחה בעברית בסימולציה של WhatsApp: קביעת תור, ביטול ומענה מתוך הקטלוג.
- שלושה שירותים: טיפול פנים (60 דק׳, 250 ₪), מניקור (45 דק׳, 100 ₪), עיצוב גבות (20 דק׳, 60 ₪).
- רשימת המתנה בהסכמה. מועד שהתפנה מוצע ללקוחה אחת בכל פעם ונשמר לה 30 דקות.
- מניעת חפיפות ביומן, ואישור נשלח רק אחרי שמירה מוצלחת.
- העברה לבעלת המכון: שאלה רפואית, החזר, תלונה, בקשה לא מובנת, שעה חריגה ושירות שאינו בקטלוג.
- תצוגת מנהלת: יומן, רשימת המתנה, פניות, שעות פעילות וחסימות.
- "מצב הצגה" להדגמת מילוי מועד שהתפנה, פקיעת הצעה וכשל בשמירה.

נדחה לשלב הבא: ערבית ואנגלית, כמה מטפלות, שינוי מועד אוטומטי, תזכורות, משוב וחיבור WhatsApp אמיתי.

## הפעלה
האפליקציה כולה היא קובץ אחד, בלי התקנה ובלי build.

אפשרות 1: לפתוח את `tor-hacham/index.html` בדפדפן (לחיצה כפולה).

אפשרות 2: להריץ שרת מקומי מתוך תיקיית הפרויקט:

```bash
cd tor-hacham
python3 -m http.server 8000
```

ואז לפתוח בדפדפן את http://localhost:8000

הנתונים נשמרים ב-`localStorage` של הדפדפן. כדי להתחיל מחדש: "מצב הצגה" ← "איפוס נתונים".
